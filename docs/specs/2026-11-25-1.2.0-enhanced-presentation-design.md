# 1.2.0 Enhanced Presentation & Audio — Design & Implementation Plan

Status: **Locked design specification** (`2026-11-25`, post-`1.1.60` `f1a6d96`).

`1.2.0` is the first Enhanced Mode minor release of *Batman: Return of the Joker*. Every feature in `1.2.0` is **pure presentation, audio, or host-UX**: `rotj-core`'s Classic simulation state (`Game`, RAM/WRAM, RNG, physics, spawning) is completely untouched. Classic Mode remains the default and stays byte-for-byte verified on every commit and release tag.

---

## 1. Versioning, Scope Boundary & Non-Negotiable Constraints

### Versioning (Strict SemVer 2.0.0)
- All `1.2.0` pillars land incrementally on `main` across sequenced commits (each commit green under `.orchestration/release-checks.sh`), then tag once as **`1.2.0`** (`Release 1.2.0`) when the full set is verified.
- `1.2.x` patches are reserved for bugfixes and non-behaviour-changing internal prep.
- **Deferred to `1.3.0`:** Widescreen (`> 256 px` view, widened spawn window, parallax width model, centered HUD, enhanced baseline input-only tapes + invariant fuzzing — the first behaviour-changing setting).
- **Deferred to `1.4.0+`:** Chapter Select & Passwords, Remastered / SNES Prototype Music, Tiled Bonus Levels, Cut-Content Restorations (`docs/CUTCONTENT.md`), Overworld Map, and Native-Res 2D Lighting.

### In Scope for `1.2.0`
1. **Settings schema & categorized NES-font menu** (scales cleanly beyond 8 rows within 256×224).
2. **Band-room map playfields** in Modern (`$D3` 0, 1, 2, 3, 6, 8) + **boss-floor bank-split sprites** (area `$04`, eliminating the last 486 Classic-fallback gameplay frames).
3. **High-refresh interpolated motion + `frame_rate` slider** (display-scale Modern target `M × 256 × 240`, curated stops + `Display` + custom `Fps(u16)`).
4. **Unlimited-voice SFX** (dedicated Music APU + 16-voice polyphonic SFX pool with soft-limited mix).
5. **CRT filter / shader** (`Off` / `Scanlines` / `Crt`, covering game picture + Faithful UI while keeping the Settings Menu crisp on top).
6. **Intro 30 Hz flicker blend** (`intro_blend`, CRT-style frame persistence on `SlideRow::Flicker`).
7. **"Load pack" menu entry** (session-only `<exe_dir>/packs/` scanner + `ORIGINAL` entry with `Source::User` validation).

### Non-Negotiable Constraints
- **Classic parity:** `.orchestration/release-checks.sh` (`GATES GREEN`, 0 sweep divergences, 0 explore divergences) and state tape byte-identical to `.orchestration/chain-1.1.14.tape`.
- **Backward compatibility:** `crates/app/settings-1.1.0.ron` parses to `Settings::default()` with zero warnings; Tiled level-pack format stays unchanged.
- **Workspace hygiene:** zero ROM data tracked (`tools/check-no-rom-data.py`), `unsafe_code = "deny"`, `clippy::pedantic` at `-D warnings`, zero `#[allow(...)]` (only inline `#[expect(clippy::needless_pass_by_value, reason = "Bevy system params, rust-clippy#8940")]` on Bevy systems), `cargo deny check`.
- **Palette credit:** FirebrandX's `COMPOSITE DIRECT FBX` credit remains displayed wherever `PALETTE` is selectable.
- **Untracked files:** never touch or stage `docs/Media Tracker and Indexer Research.txt`.
- **Git hygiene:** one-line commit subjects, no `Co-Authored-By` trailer.

## 2. Public Interface (`settings.ron`) & Settings Menu Redesign

### `settings.ron` Schema (`crates/app/src/settings.rs`)

All existing `1.1.0` fields (`volume`, `overscan`, `palette`, `sprite_limit`, `vsync`, `ui`, `picture`) keep their exact names, variants, and Classic defaults. Four new public fields are added:

```rust
/// Display refresh / motion interpolation target.
#[derive(Serialize, Deserialize, Clone, Copy, Debug, Default, PartialEq, Eq)]
pub(crate) enum FrameRate {
    /// NES 60 Hz locked, 1 picture per tick, zero interpolation latency (default).
    #[default]
    Classic,
    /// Fixed target FPS (clamped 60..=480; 60 behaves identically to `Classic`).
    Fps(u16),
    /// Match display refresh / VSync via `UpdateMode::Continuous`.
    Display,
}

/// Post-process CRT presentation preset.
#[derive(Serialize, Deserialize, Clone, Copy, Debug, Default, PartialEq, Eq)]
pub(crate) enum CrtFilter {
    /// Unfiltered nearest-neighbor pixels (default).
    #[default]
    Off,
    /// Flat NES-row-aligned scanlines with brightness compensation.
    Scanlines,
    /// Scanlines, subtle aperture grille, barrel curvature, phosphor glow, and vignette.
    Crt,
}

/// Audio voice allocation for sound effects.
#[derive(Serialize, Deserialize, Clone, Copy, Debug, Default, PartialEq, Eq)]
pub(crate) enum SfxVoices {
    /// Single 2A03 APU shared by music and SFX, write-exact to the NES (default).
    #[default]
    Classic,
    /// Dedicated Music APU plus a polyphonic SFX voice pool (SFX never steal music channels).
    Unlimited,
}
```

Added fields on `Settings`:
- `pub frame_rate: FrameRate` (default: `FrameRate::Classic`)
- `pub crt: CrtFilter` (default: `CrtFilter::Off`)
- `pub sfx_voices: SfxVoices` (default: `SfxVoices::Classic`)
- `pub intro_blend: bool` (default: `false`)

Backward/forward compatibility rules:
- `Fields` continues using per-field `Option<Box<RawValue>>` so unknown keys or unknown enum variants warn and fall back individually without discarding other settings.
- `FrameRate::Fps(n)` is clamped on parse to `60..=480` (if `n == 60`, behaves identically to `FrameRate::Classic` at runtime while preserving round-trip fidelity).
- Keep `crates/app/settings-1.1.0.ron` unmodified and tested; add `crates/app/settings-1.2.0.ron` covering all `1.2.0` defaults. Update `an_unknown_key_is_ignored` in `settings.rs` to test a genuinely unknown key (e.g., `future_option: Foo`) since `frame_rate` is now a real key.

### Categorized Submenu Architecture (`crates/app/src/menu.rs`)

At `1.1.60`, the flat 8-row menu takes `212 px` of the `224 px` visible height (`overscan: Hidden`), leaving 0 rows of vertical room. `1.2.0` replaces the flat `Row` list with a compact two-level submenu tree where **every screen fits inside `256 × 224` NES pixels**:

| Screen | Header | Rows (with `BACK`) | Footer / Credit | Height (`overscan: Hidden`) |
| --- | --- | --- | --- | --- |
| **Root** | `SETTINGS` | `DISPLAY`, `GRAPHICS`, `AUDIO`, `LOAD PACK`, `BACK` (5) | `SAVE FAILED` if save failed | `164 px` (`<= 224`) |
| **Display** | `DISPLAY` | `PALETTE`, `OVERSCAN`, `CRT`, `VSYNC`, `FRAME RATE`, `BACK` (6) | `COMPOSITE DIRECT FBX` (when `CompositeDirect`) + `NEEDS MODERN PICTURE` (only when `frame_rate != Classic && picture == Classic`, replacing blank spacer or on dedicated line — max 7 rows + 2 headers/footers = `<= 212 px`) | `<= 212 px` (`<= 224`) |
| **Graphics** | `GRAPHICS` | `PICTURE`, `UI`, `SPRITE LIMIT`, `INTRO BLEND`, `BACK` (5) | *(room for `WIDESCREEN` in `1.3.0`)* | `148 px` (`<= 224`) |
| **Audio** | `AUDIO` | `VOLUME`, `SFX VOICES`, `BACK` (3) | *(room for `SOUNDTRACK` in `1.4.0`)* | `116 px` (`<= 224`) |
| **Load Pack** | `LOAD PACK` | Scrollable viewport of up to 6 visible entries (`ORIGINAL` + discovered packs) + `BACK` | `NO PACKS` when empty, or `PACK INVALID` on failed load | `<= 212 px` (`<= 224`) |

Navigation & input rules:
- **Open/Close:** `Esc`, `F1`, gamepad Guide/Right-Stick anywhere, or `Select` on the game's pause screen. Closing from any screen saves `settings.ron` once (ignoring pack selection, which is session-only).
- **Submenu stack:** `A` / `Start` enters a category or executes `LOAD PACK` / `BACK`; `B` steps back one level (from a submenu to Root, or from Root closes & saves).
- **Held-button repeat:** `UP`/`DOWN`/`LEFT`/`RIGHT` support initial delay (`~20` frames / `333 ms`) + repeat interval (`~4` frames / `66 ms`) so sweeping `VOLUME` and `FRAME RATE` feels responsive on keyboard and gamepad.
- **NES font constraint:** every label, value, header, and notice uses only characters present in `menu::glyph()` (`A-Z`, `0-9`, `' '`, `'?'`, `'-'`, `'.'`). Existing tests (`every_menu_character_has_a_glyph`, `the_box_fits_the_smallest_view`, `only_composite_direct_is_credited`) are expanded to cover every submenu screen.

## 3. Pillar 1 — Band-Room Map Playfields & Boss-Floor Bank-Split Sprites

### 3a. Band-Room Playfields from the Live Map (`rotj-core::sim::modern`, `crates/app/src/modern.rs`)

Currently, every armed raster split outside `Chain::BossBar` sets `map_end = 0` and draws all lines from PPU nametables (`docs/specs/archive/2026-10-30-modern-band-rooms-design.md` "Not here"). In `1.2.0`, every band room's gameplay playfield is drawn directly from `tile_at(game, ..)` (giving smooth sub-pixel camera interpolation now and preparing for >256 px map reads in `1.3.0` Widescreen):

| Raster Chain (`$D3`) | Playfield Band(s) from Live Map | Parallax / Fixed Nametable Runs |
| --- | --- | --- |
| `0` (`TwoBands`, area `$02`) | IRQ 2's run (`line ~126..240`) | Top 2 parallax bands |
| `1` (`ThreeBands`, area `$10`) | IRQ 3's run (`line ~143..240`) | Top 3 parallax bands |
| `2` (`FixedRow`, area `$12`) | Top run (`0..~161`) | Fixed bottom row (`$2680`) |
| `3` (`BossFloor`, area `$04`) | Line 0's run (above IRQ 2 floor) | Top parallax band(s) + fixed x=0 floor + status bar |
| `4` (`BossBar`) | Top run (`0..~192`, outside area `$22`) | Status bar runs (area `$22` remains all-nametable because part destruction patches nametables directly via `$A0CE`) |
| `5` (`FourBands`, area `$08`) | None (all parallax) | All runs from nametables |
| `6` (`SwingingRow`, area `$0C`) | Run from line `~141` (`$2620` row) | Upper swinging band(s) |
| `7` (`FourBandsTall`, area `$18`) | None (all parallax) | All runs from nametables |
| `8` (`FixedTop`, area `$1C`) | Lines `0..~111` AND IRQ 2's run (`~194..240`) | Middle fixed art (`~111..194`) |

Model change in `crates/rotj-core/src/sim/modern.rs`:
- Replace `View { map_end: usize, runs: Runs, .. }` with a unified ordered slice/array of `Piece` descriptors (fixed-capacity `Copy` array, `MAX_PIECES = MAX_RUNS + 2`):
  - `Piece::Map { line: usize, end: usize, banks: [u8; 4] }` — screen lines `[line, end)` drawn from `ModernFrame::tiles` using `(view.left, view.top)` and `banks`.
  - `Piece::Run(Run)` — screen lines `[run.line, run.end)` drawn from nametables via `run_tile`.
- `check_background` validates every `Piece::Map` span against `tile_at` over TV-visible lines (`8..232`) and every `Piece::Run` via `check_run`.
- `crates/app/src/modern.rs` renders each `Piece` on its dedicated `Layer` camera clipped to `line..end`, with zero change to non-split frames.

### 3b. Boss-Floor Bank-Split Sprites (Area `$04`)

In `1.1.60`, 486 of 503 frames in Stage 1's boss room (`area $04`) fall back to Classic because Batman's 8×16 sprites straddle the scanline where FME-7 swaps `sprite_chr` banks (`sprites_steady` returns `false`).

Fix:
- Remove the `sprites_steady` rejection for gameplay frames (or restrict it only to invalid/non-rendered edge cases, keeping `sprites_steady` logic as a helper for identifying split sprites).
- In `crates/app/src/modern.rs::spawn_sprites`, inspect `lines[y+1..(y+17).min(240)]` for each visible 8×16 sprite's `sprite_chr` table:
  - **Common case (steady banks):** spawn 1 sprite entity exactly as today.
  - **Bank-split case:** partition the 16 sprite rows into contiguous bank-uniform slices (at most 2 slices per 8×16 sprite). For each slice `[row_start..row_end)` (handling `flip_y` correctly when computing atlas sub-rect!), compute `sprite_key` at `y + 1 + row_start` and spawn a `ModernSprite` with `Sprite::rect` clipped to that slice's vertical rows and `Transform` positioned at `-(y + 1 + row_start)`.
- **Expected result:** `classic_splits` drops from `486` to `0` across the entire 48,100-frame TAS lockstep, verified pixel-for-pixel against Classic by a new headless render test in area `$04`.

## 4. Pillar 2 — High-Refresh Interpolated Motion & `frame_rate`

### 4a. Pacing & Fixed-Timestep Loop (`crates/app/src/pacing.rs`)

- **Classic mode (`FrameRate::Classic`, or `FrameRate::Fps(60)`):**
  - Preserves exact `1.1.60` pacing: `UpdateMode::Reactive { wait: PERIOD, .. }`, `alpha = 1.0`, zero interpolation latency, zero extra CPU/GPU work.
- **High-refresh mode (`FrameRate::Display` or `FrameRate::Fps(n)` with `n > 60`):**
  - `WinitSettings` switches dynamically to `UpdateMode::Continuous` (updates live whenever `settings.frame_rate` changes).
  - For `FrameRate::Fps(n)`, a monotonic frame-deadline limiter caps presentation cleanly at `1 / n` seconds (using sleep for coarse wait + short final yield) so turning `vsync: false` never busy-spins at thousands of FPS.
  - `Clock` maintains a 60 Hz fixed-timestep accumulator (`acc += dt.min(4 * PERIOD)`):
    - Runs `Step::Game` + `Step::Music` + `Mirror` snapshot update once per `PERIOD` consumed (`0..=4` ticks per render frame, spiral-of-death clamped).
    - Exposes `alpha = (acc / PERIOD).clamp(0.0, 1.0) as f32` for `Step::Picture`.
  - **Input latching (`input.rs`):** keyboard and gamepad edge presses (`just_pressed`) arriving on non-tick render frames are OR-latched into `NesInput` until consumed by the next 60 Hz tick, ensuring zero dropped jumps/shots at 120–360 Hz.
  - **Menu stepping order (`FRAME RATE`):** curated stops `[60, 75, 90, 120, 144, 165, 170, 240, 360, DISPLAY]`. If `settings.ron` holds a custom `Fps(n)` (e.g., `Fps(100)`), the menu displays `100` and Left/Right steps to the nearest curated stop below/above it.

### 4b. Classic Interaction & Display-Scale Modern Target (`crates/app/src/modern.rs`, `main.rs`)

- **When `picture == Picture::Classic`:** Classic PPU stays 60 Hz exact (no interpolation; `Step::Picture` only uploads when a tick ran or palette/settings changed). The `DISPLAY` submenu shows `NEEDS MODERN PICTURE` when `frame_rate != Classic && picture == Classic`.
- **When `picture == Picture::Modern` and `frame_rate != Classic` (active gameplay, menu closed):**
  - `Modern`'s offscreen `RenderTarget::Image` dynamically sizes to `M × 256 × M × 240`, where `M >= 1` is `fit_camera`'s current integer multiple (capped to e.g. `max_scale = 8` / `2048×1920` to stay well within GPU texture limits).
  - Each `Layer` camera viewport scales to `(0, line * M)` with size `(256 * M, (end - line) * M)` and orthographic scale `1.0 / M` (world units stay in NES pixels `[0..256, -240..0]`).
  - Because all tileset and sprite textures use `ImagePlugin::default_nearest()`, every NES pixel remains razor-sharp while sub-NES-pixel transforms move smoothly in `1 / M` NES-pixel increments!
  - When `frame_rate == Classic`, the Modern target stays `256 × 240` (`M = 1`), preserving exact `1.1.60` pixel-parity behavior and headless tests.

### 4c. Snapshot History & Interpolation/Snap Rules (`mirror.rs`, `modern.rs`)

Add `InterpolationHistory` resource updated on every 60 Hz gameplay tick:
- Stores `(prev_tick, curr_tick)` copies of:
  - `(area, room)` identifier (exposed via read-only `Session::room_id() -> (u8, u8)` — zero sim change).
  - `FrameSnapshot` (`drawers`, `camera`, `modern: Option<ModernFrame>`).
- **Camera / Map Playfield interpolation:**
  - Compute `prev_cam = (prev.view.left as f32, prev.view.top as f32)` and `curr_cam = (curr.view.left as f32, curr.view.top as f32)` (or exact 1/16 px camera delta when no screen shake is active).
  - **Snap (use `curr_cam` directly)** if: `prev` missing, `(area, room)` changed, `paused`, `|Δx| > 16.0`, or `|Δy| > 16.0`.
  - Otherwise `interp_cam = prev_cam.lerp(curr_cam, alpha)`.
  - Expand `ModernFrame` tile fetch by 1 extra guard column/row on the leading/trailing edge (or `COLUMNS + 1`, `ROWS + 1`) so fractional negative/positive sub-pixel offsets never expose an empty 1-pixel border.
- **Parallax Nametable Runs interpolation:**
  - Match each `Piece::Run` at index `i` against `prev`'s run at index `i`: if `line == prev.line`, `end == prev.end`, and `top.mirroring == prev.top.mirroring`, compute horizontal pixel scroll `sx = ((nt_x * 32 + coarse_x) * 8 + fine_x)` in `[0..512)`, take shortest signed delta mod 512, and if `|Δsx| <= 16`, lerp `sx` by `alpha`; otherwise snap.
- **Sprite / Drawer interpolation:**
  - For each `DrawRecord` owned by a drawer entity (`Mark::{Player, Actor(i), Second(i), Projectile(i)}`):
    - Look up `prev_drawer` and `curr_drawer` in `InterpolationHistory` by `Mark`.
    - **Snap** if: `prev_drawer` missing, `curr_drawer.kind != prev_drawer.kind` (slot reuse!), `curr_drawer.kind == Some(0)`, `(area, room)` changed, or world displacement `|Δworld_x| > 16.0` or `|Δworld_y| > 16.0` (teleports/respawns/wraps).
    - Otherwise compute interpolated world position `interp_world = prev_pos.lerp(curr_pos, alpha)` (in 1/16 px -> `f32` pixels) and apply the net screen-space offset `Δscreen = (interp_world - curr_world) - (interp_cam - curr_cam)` to each of that drawer's `OamEntry` positions.
    - Note why computing `(interp_world - curr_world) - (interp_cam - curr_cam)` is exact: at `alpha = 1.0`, `Δscreen == (0, 0)` (reproducing `curr` OAM coordinates bit-for-bit); at `alpha = 0.0`, it shifts smoothly back to `prev`'s screen position even while the camera is scrolling!
  - `Mark::{Hud, Label, Pause, Title, Password, Scene}` are never interpolated (`Δscreen = 0`).

## 5. Pillar 3 — Unlimited-Voice SFX (`crates/rotj-music`, `crates/app/src/audio.rs`)

### `rotj-music` Additions (Zero Behaviour Change to Existing API)
- Add `pub enum SoundKind { Music, Sfx, Command }` and `pub const fn classify_request(id: u8) -> SoundKind`:
  - `0x00..=0x1F` -> `SoundKind::Music`
  - `0x20..=0xF7` -> `SoundKind::Sfx`
  - `0xF8..=0xFF` -> `SoundKind::Command`
- Add `pub fn is_idle(&self) -> bool` on `rotj_music::Music` (returns `true` when all 8 music/SFX channels and both DMC SFX channels have `ACTIVE` and `PARKED` clear).

### Dual-Path Synth Engine (`crates/app/src/audio.rs`)
- `Music` resource holds:
  - `primary: (rotj_music::Music, ApuStream)` — handles everything in `SfxVoices::Classic`; handles Music + Commands only in `SfxVoices::Unlimited`.
  - `sfx_pool: Vec<SfxVoice>` (lazily populated up to `MAX_SFX_VOICES = 16`, each owning `(rotj_music::Music, ApuStream)` initialized with fixed PRG bank 15 DMC sample ROM + `driver.init()`, plus `age: u64` for oldest-voice stealing).
  - `prg_bank15: Vec<u8>` + `driver_template: rotj_music::Music` (cloned on pool spawn so allocating a voice is fast and allocation-minimal).
- **Routing (`Music::request(id, sfx_voices)`):**
  - `SfxVoices::Classic`: forwards all requests directly to `primary.driver.request(id)` (100% identical to `1.1.60`).
  - `SfxVoices::Unlimited`:
    - `SoundKind::Music` -> `primary.driver.request(id)`.
    - `SoundKind::Command`:
      - `StopAll` (`$F8..=$FB`, `$FF`): forwarded to `primary` AND resets/silences all active `sfx_pool` voices.
      - `ParkActive` (`$FE`) / `ResumeParked` (`$FD`) / `StartFade` (`$FC`): forwarded to `primary` (letting pause chime SFX ring out naturally on the pool, just like NES!).
    - `SoundKind::Sfx` -> acquires an idle `SfxVoice` (or spawns one up to 16, or steals the oldest active voice), resets its driver (`init()` applied to its APU), and calls `voice.driver.request(id)`.
- **Mixing & Headroom (`Music::advance_frame`):**
  - `AudioDrive::Frozen` (settings menu open): freezes `primary` and all `sfx_pool` voices and ramps gain smoothly to `0.0` over 10 ms.
  - `AudioDrive::Running`: ticks `primary`, ticks each active `SfxVoice` (marking idle voices inactive once `driver.is_idle()` and APU output settles), fills each buffer, sums `mix = primary_buf[i] + sum(sfx_bufs[i])`.
  - Applies transparent soft-clipping when `sfx_pool` contributed (`soft_clip(x)`: identity for `|x| <= 0.85`, smooth `0.85 + 0.15 * tanh((|x| - 0.85) / 0.15)` beyond `0.85`), ensuring normal single-APU output is bit-for-bit untouched while 16-voice bursts never clip past `[-1.0, 1.0]`.
- **Live toggle:** switching `Classic <-> Unlimited` mid-stage never drops the currently playing music track because `primary` always owns music state.

## 6. Pillar 4 — CRT Filter / Shader (`crates/app/src/crt.rs`, `crt.wgsl`, `screen.rs`, `ui.rs`, `menu.rs`)

### Camera & Composite Pipeline
To ensure CRT effects cover **both the game picture AND `ui: Faithful`** (HUD, pause card, title cursor, password) while keeping the **Settings Menu crisp and un-curved on top**:

1. **When `crt == CrtFilter::Off` (Classic default):**
   - Pipeline stays identical to `1.1.60` (no extra render pass, zero shader cost, pixel-exact nearest-neighbor).
2. **When `crt != CrtFilter::Off`:**
   - **Game Composite Target (`CrtCompositeImage`):** sized to `M × (visible.width, visible.height)` (matching `fit_camera`'s integer scale).
     - `GameStageCamera` (`order = 0`, `RenderTarget::Image(composite)`) renders the screen quad (`Classic` or `Modern`).
     - `Faithful UI` root (`ui.rs`) attaches `UiTargetCamera(game_stage_camera)` so Bevy renders the Faithful HUD/pause sprites directly onto `composite` before CRT post-processing!
   - **CRT Display Pass (`ScreenCamera`, `order = 1`, window target):**
     - Draws a single letterboxed `Mesh2d` quad with `CrtMaterial` (`Material2d`, safe Rust + `crt.wgsl` embedded via `include_str!` / `Shader::from_wgsl`).
   - **Menu Overlay Camera (`MenuCamera`, `order = 2`, `ClearColorConfig::None`, window target):**
     - Settings Menu (`menu.rs`) targets `UiTargetCamera(menu_camera)` so `SETTINGS` and `PAUSE HINT` remain crisp, flat, and readable regardless of CRT curvature.

### WGSL Shader (`crates/app/src/crt.wgsl`)
Uniforms passed via `CrtUniform`:
- `mode: u32` (`1 = Scanlines`, `2 = Crt`)
- `source_size: Vec2` (NES visible pixels, e.g. `256.0 × 224.0` or `256.0 × 240.0`)
- `output_size: Vec2` (drawn quad size in physical pixels)

Shader stages:
- **`Scanlines` (`mode == 1`):**
  - Sample texture cleanly (no curvature), compute scanline weight from `fract(uv.y * source_size.y)` (softened dark trough at sub-row edges, zero moiré at integer scales), apply ~1.12× brightness lift + clamp so perceived brightness matches unfiltered output.
- **`Crt` (`mode == 2`):**
  - Subtle barrel distortion (`k ≈ 0.06`, returning solid black outside `[0, 1]²` with clean anti-aliased edge).
  - Sample sharp core + lightweight 5-tap horizontal phosphor glow/halation (`~12%` additive blend on bright pixels).
  - NES-row-aligned scanlines modulated by pixel luminance (brighter phosphors bloom slightly wider, like a real CRT beam).
  - Subtle vertical RGB aperture grille mask scaled to output pixels (`~8–12%` modulation so text stays legible even at 720p/1080p).
  - Gentle radial edge vignette.

## 7. Pillar 5 — Intro 30 Hz Flicker Blend (`rotj-core`, `crates/app/src/screen.rs`)

- **Core hook (read-only, zero RAM/state impact):**
  - Add `Boot::is_flickering(&self) -> bool` returning `true` iff `self.step == Step::Slide` and the current `SlideRow` is `SlideRow::Flicker`.
  - Expose `Session::intro_flickering(&self) -> bool` (forwards through `Game::script` when `Some(Script::Boot(boot))`).
- **Presentation blend (`crates/app/src/screen.rs`):**
  - `Screen` holds an optional `prev_rgba: Option<Vec<u8>>` buffer.
  - When `settings.intro_blend && play.session().intro_flickering()`:
    - Compute current tick's RGBA into a scratch buffer.
    - If `prev_rgba` is present, upload `out[i] = ((u16::from(prev[i]) + u16::from(curr[i])) / 2) as u8` (preserving alpha `0xFF`), then store `curr` as `prev_rgba`.
  - Whenever `!settings.intro_blend || !play.session().intro_flickering()`: clear `prev_rgba` immediately and upload `curr` untouched.

## 8. Pillar 6 — "Load Pack" Menu Entry (`crates/app/src/packs.rs`, `menu.rs`, `play/mod.rs`)

### Discovery (`crates/app/src/packs.rs`)
- Given `exe_dir: Option<&Path>`, scans `<exe_dir>/packs/`:
  - Lists immediate subdirectories containing a `pack.json` file (case-insensitive check, matching `main.rs`; skips symlinks/unreadable entries cleanly without panicking).
  - Sorts entries alphabetically by folder name.
  - Always provides `"ORIGINAL"` as entry 0.
  - Maps folder names to NES-font display labels (uppercase, `_` -> `-`, unknown characters -> `' '`, truncated cleanly to fit `COLUMNS - 2`).
- Re-scans `<exe_dir>/packs/` each time the player enters the `LOAD PACK` submenu (so dropping a new pack into `packs/` while the game is running appears immediately without restarting!).

### Hot-Swap Lifecycle
- Selecting **`ORIGINAL`**:
  - Calls `Levels::original(&rom.0.prg, &rom.0.chr)`.
  - Replaces `GameLevels`, rebuilds `Play::power_on(Prg::new(rom.0.prg.clone(), levels), rom.0.chr.clone(), None)`, resets `Music` (clean `init()` + clears SFX pool), clears `InterpolationHistory` and `Screen::prev_rgba`, transitions `NextState<GameState>` to `GameState::Title`, and closes the menu.
- Selecting a **pack folder**:
  - Calls `crate::pack_levels(&rom.0, &entry.dir)` (runs full `Source::User` crash-hardening validation).
  - On `Ok(levels)`: performs the exact same clean hot-swap reset to `GameState::Title` and closes the menu.
  - On `Err(reason)`: logs `warn!("{}: {reason}", entry.dir.display())`, leaves the active `Play`, `GameLevels`, and `Music` completely untouched, and displays `PACK INVALID` in the `LOAD PACK` submenu footer.
- **Session-only:** never written to `settings.ron`. Next launch always starts on Original Classic unless `--pack` CLI arg is passed.
