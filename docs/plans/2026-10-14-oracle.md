# 6502 Oracle Implementation Plan

> **For agentic workers:** Implement task-by-task, in order. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a dev-only crate that runs the game's own frames from power-on, so the port can be diffed against the original in `cargo test`.

**Architecture:** `tools/rotj-oracle`: a 2A03 CPU generic over a `Bus` trait, a bus with RAM/WRAM/FME-7/register-level PPU/APU log/controller, and a `Machine` that steps whole frames. Validated against fceux's `tools/emu/run1` RAM sequence (3000 frames from power-on).

**Tech Stack:** Rust 2024 (workspace `rust-version = "1.99.0"`), std only.

**Spec:** `docs/specs/2026-10-14-oracle-design.md`

## Global Constraints

- No `unsafe` (workspace lint `unsafe_code = "deny"`); no new dependencies (`cargo deny check` must pass).
- Workspace lints apply (`[lints] workspace = true`): clippy pedantic, `missing_docs`. Gates: `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --check`.
- Never add lint suppressions (`#[allow]`, `#[expect]`, config excludes). Fix the finding.
- Comments: one-line doc comments on public items (the lint needs them); otherwise only when the code cannot say it.
- `Cargo.toml`: `publish = false`, `version.workspace = true`, `edition.workspace = true`, `license.workspace = true`, `rust-version.workspace = true`, like `tools/rotj-verify`. Add the crate to the workspace `members`.
- The ROM is `raw/Batman - Return of the Joker (USA).nes` (git-ignored). Tests that need it print `skipped: ROM not found at <path>` and return when it is absent.
- The crate has no workspace dependencies.
- Do not edit `docs/STATUS.md`.

## Review Focus

1. `JMP ($xxFF)` fetches the high byte from `$xx00` (6502 page-wrap bug) — Task 1 test `jmp_indirect_wraps_within_page`.
2. Zero-page indexed and `(zp),Y` pointer fetches wrap inside page 0 — Task 1 test `zero_page_indexing_wraps`.
3. `$2007` reads are buffered except palette reads; `$2002` reads clear vblank and the `$2005/$2006` toggle — Task 3 tests.
4. Writing `$2000` with bit 7 set while the vblank flag is set raises an NMI immediately — Task 3 test `nmi_enable_during_vblank_fires`.
5. FME-7 `$6000`: cmd 8 bit 6 = RAM enable, bit 7 = RAM select; ROM-mapped or disabled `$6000` ignores writes — Task 2 test `wram_requires_select_and_enable`.

### Task 2: Cartridge, FME-7, bus, APU log, controller

**Files:**
- Create: `tools/rotj-oracle/src/cart.rs`, `src/fme7.rs`, `src/bus.rs`

**Interfaces:**
- Consumes: `Bus` (Task 1).
- Produces:
  - `pub struct Cart { pub prg: Vec<u8>, pub chr: Vec<u8> }`; `Cart::from_ines(bytes: &[u8]) -> Result<Cart, String>` (16-byte header, mapper 69 required, PRG `header[4]*16 KiB`, CHR `header[5]*8 KiB`); `pub fn rom_path() -> PathBuf` (workspace `raw/Batman - Return of the Joker (USA).nes`); `pub fn load_rom() -> Option<Cart>` (None when absent).
  - `pub struct Fme7 { pub command: u8, pub chr: [u8; 8], pub prg: [u8; 4], pub mirroring: u8, pub irq_control: u8, pub irq_counter: u16 }`; `Fme7::write(&mut self, addr: u16, value: u8)` (`$8000-$9FFF` command, `$A000-$BFFF` parameter); `Fme7::prg_offset(&self, addr: u16, prg_len: usize) -> Option<usize>` (`$6000` via cmd 8 when ROM-selected, `$8000/$A000/$C000` via cmds 9/A/B, `$E000` = last 8 KiB bank); `Fme7::wram_enabled(&self) -> bool`; `Fme7::clock(&mut self, cycles: u32) -> bool` (counter decrements when bit 7 of control is set; returns true on underflow when bit 0 is set).
  - `pub struct WriteLog { pub pc: u16, pub addr: u16, pub value: u8 }` (`Clone`, `Debug`, `PartialEq`).
  - `pub struct NesBus { pub ram: [u8; 2048], pub wram: [u8; 8192], pub cart: Cart, pub fme7: Fme7, pub ppu: Ppu, pub pad: u8, pub pc: u16, pub apu_log: Vec<WriteLog>, pub mapper_log: Vec<WriteLog>, pub dma_stall: u32 }` implementing `Bus`. `pad` is the controller byte (NES bit order A,B,Select,Start,Up,Down,Left,Right = bits 0..7 as read out); `$4016` write bit 0 strobes, reads shift one bit out in bit 0. `$4000-$4013`, `$4015`, `$4017` writes go to `apu_log`; `$4015` reads return 0. `$4014` copies a page to `ppu.oam` and sets `dma_stall` to 513 (514 on an odd CPU cycle). `$8000-$BFFF` writes also go to `mapper_log`. `pc` is set by the caller before each instruction and stamped on logs.
  - `Ppu` is a stub with `pub oam: [u8; 256]` and `read_register/write_register` returning 0 / doing nothing, replaced in Task 3.

### Task 4: Machine and frame stepping

**Files:**
- Create: `tools/rotj-oracle/src/machine.rs`; `lib.rs` re-exports `Machine`, `FrameLog`, `Cart`, `load_rom`.

**Interfaces:**
- Consumes: Tasks 1-3.
- Produces: `pub struct Machine { pub cpu: Cpu, pub bus: NesBus, pub frame: u64 }` (`Clone`); `Machine::power_on(cart: Cart) -> Machine` (RAM fill from `PowerOnRam`, reset); `pub enum PowerOnRam { Zero, Ff, Fceux }` with `Machine::power_on_with(cart, PowerOnRam)`; `Machine::run_frame(&mut self, pad: u8) -> FrameLog`; `pub struct FrameLog { pub apu: Vec<WriteLog>, pub ppu: Vec<WriteLog>, pub mapper: Vec<WriteLog>, pub cycles: u32 }`; snapshots are `Machine::clone()`.
- Timing (NTSC): 341 dots per scanline, 262 scanlines, 3 dots per CPU cycle, odd frames one dot shorter when rendering is on. Vblank set at scanline 241 dot 1, cleared with sprite-0 at scanline 261 dot 1. Sprite-0 hit is set at the first scanline in `oam[0]+1 .. oam[0]+9` (or `+17` in 8x16 mode) when `mask` has both background and sprites enabled. NMI is taken before the next instruction after `nmi_pending`. FME-7 IRQ is clocked every CPU cycle and asserted to the CPU while pending. `run_frame` returns when the frame has run from one vblank start to the next; Task 5 measures how that lines up with fceux's frame counter.

- [ ] **Step 1: Failing tests (ROM-gated):** `boots_to_the_reset_vector` (PC after power-on = little-endian word at the last bank's `$1FFC`), `runs_a_frame_without_panicking` (60 frames, `frame == 60`), `nmi_handler_runs_once_per_frame` (count entries to the NMI vector over 10 frames = 10 once NMIs are enabled), `snapshot_restores_exactly` (clone at frame 100, run 50 frames on both copies, RAM equal).
- [ ] **Step 2: Run** — fails.
- [ ] **Step 3: Implement.**
- [ ] **Step 4: Run** tests and gates.
- [ ] **Step 5: Commit** `oracle: machine and frame stepping`.
