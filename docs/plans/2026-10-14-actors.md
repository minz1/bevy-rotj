# Actor Core Implementation Plan

> **For agentic workers:** Implement task-by-task, in order. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the pure actor core in `rotj-core` (slots, spawners, metasprites, OAM builder, the actor loop) with an oracle phase-diff harness, proven by porting actor type `$0A`.

**Architecture:** `crates/rotj-core/src/actor/` holds the game's actor state as typed Rust and ports the actor loop (`$CED5`), the spawners (`$87C5`, `$D714`), the bank-13 engine routines `$0A` calls and the OAM builder (`$C247`/`$C145`). Test-only code lifts that state from oracle RAM and projects it back; every test brackets one game routine with two oracle peeks and compares every RAM/WRAM byte either side changed. App wiring and the fan-out are later plans.

**Tech Stack:** Rust 2024 (workspace `rust-version = "1.99.0"`), std only; `rotj-oracle` as a dev-dependency of `rotj-core`.

**Spec:** `docs/specs/2026-10-14-actors-design.md`

## Global Constraints

- No `unsafe`; no new external dependencies (`cargo deny check` passes). `rotj-core` gains only `rotj-oracle = { version = "0.1.0", path = "../../tools/rotj-oracle" }` under `[dev-dependencies]`.
- Workspace lints (clippy pedantic, `missing_docs`). Gates: `ROTJ_REQUIRE_ROM=1 cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --check`.
- Never add lint suppressions (`#[allow]`, `#[expect]`, config excludes). Fix the finding.
- Comments: one-line doc comments on public items (the lint needs them); otherwise none unless the code cannot say it. A doc line names the 6502 routine a function ports (`$A8E4`).
- Idiomatic Rust: no 6502-shaped code in shipped modules, no trait with one implementation, no speculative abstraction. RAM layout lives only in `#[cfg(test)]` code.
- Units: level positions are `u16` in 1/16 px (the game's `$7B00:$7B20`); screen positions `i16` px; `View` fields `i32` in 1/16 px.
- ROM-gated tests use `rotj_oracle::power_on()`: skip with a notice when `raw/` is absent, panic when `ROTJ_REQUIRE_ROM` is set.
- Commits: one short subject line, no trailers. Commit only the files the task names.

## Review Focus

- A slot freed and reused keeps the arrays the new record does not write (residue): Task 4 `spawn_keeps_residue`.
- A column spawn with all 16 slots taken leaves the cell pending, as `$8842` returns before `AND #$3F`: Task 4 `full_slots_leave_the_cell_pending`.
- OAM overflow differs on even and odd frames (`$F7` bit 7): Task 2 `forced_cases_match_the_oracle` (overflow on both parities).
- An actor left of the camera, or more than 128 px past either edge, is off screen, near (`$80`) or far (`$C0`): Task 5 `on_screen_classifies_both_margins`.
- An NMI inside a bracketed routine makes the pair meaningless: Task 3 `pairs_with_an_nmi_between_are_rejected`.
