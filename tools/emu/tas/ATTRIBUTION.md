# The published TAS

`inputs.csv` is the controller input of the tool-assisted speedrun
**"Batman: Return of the Joker" by Aglar** (11:21.57, FCEU 0.98.16), published
by TASVideos as [1087M](https://tasvideos.org/1087M), converted from its `.fcm`
movie with `tools/emu/fcm2csv.py`.

TASVideos content is licensed under
[Creative Commons Attribution 2.0](https://creativecommons.org/licenses/by/2.0/)
([site license](https://tasvideos.org/SiteLicense)). The conversion changes the
format only: one `frame,pad` row per frame, the input unchanged.

`tools/emu/fetch-tas.sh` re-downloads the movie and regenerates the file.
